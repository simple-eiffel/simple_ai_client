Overview

simple_ai_client provides an Eiffel client for AI APIs including Claude and other LLM services. Includes support for vector embeddings and semantic similarity search.

Part of the simple_* ecosystem of focused, single-purpose Eiffel libraries.

Quick Start

Installation

Add to your ECF file:

<library name="simple_ai_client" location="$SIMPLE_AI_CLIENT/simple_ai_client.ecf"/>

Basic Usage

local
    client: AI_CLIENT
    response: STRING
do
    create client.make_with_api_key (api_key)
    response := client.complete ("Explain Design by Contract")
end

Features

  • Claude API integration (CLAUDE_CLIENT; key never on the command line)
  • Claude Code CLI provider on a Claude subscription, no API key (CLAUDE_CODE_CLIENT)
  • Claude Code CLI sandbox flags: tools off, settings sources pinned, strict MCP (set_tools_disabled, set_setting_sources, set_strict_mcp_config, verified by extra_arguments)
  • Claude Code CLI session resume: set_resume_session adds --resume "<uuid>"; only a UUID shape is accepted
  • Local llama.cpp server (LLAMA_SERVER_SETTINGS, LLAMA_SERVER, LLAMA_CPP_CLIENT, LLAMA_REPLY_DECODER): starts and stops llama-server on 127.0.0.1 only, tied to your program; context fitted to free GPU memory (set_context_size (0)); multi-token prediction (enable_mtp); reasoning effort per request (set_reasoning_effort, default: the template's) and a thinking switch (turn_thinking_off); thinking kept apart from the answer (last_reasoning); replies streamed to two agents as they are written (chat_streaming). Measured on an RTX 5070 Ti with Swift 1.5 / Qwen 3.8 27B: 78–126 tokens/s at a fitted 46,848-token window. Lockable against web pages in the user's own browser: an API key (set_api_key on settings and client) and allow_local_origins_only (--cors-origins localhost, build 12069+).
  • Correct Unicode round-trip: all provider output is UTF-8-decoded once at the byte boundary, and every request body is UTF-8-encoded the same way
  • Vector embedding support
  • Semantic similarity search
  • Environment variable configuration
  • Full Design by Contract support
