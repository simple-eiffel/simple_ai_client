Overview

simple_ai_client provides an Eiffel client for AI APIs including Claude and other LLM services. Includes support for vector embeddings and semantic similarity search.

Part of the simple_* ecosystem of focused, single-purpose Eiffel libraries.

Quick Start

Installation

Add to your ECF file:

<library name="simple_ai_client" location="$SIMPLE_AI_CLIENT/simple_ai_client.ecf"/>

Basic Usage

local
    client: AI_CLIENT
    response: STRING
do
    create client.make_with_api_key (api_key)
    response := client.complete ("Explain Design by Contract")
end

Features

  • Claude API integration (CLAUDE_CLIENT; key never on the command line)
  • Claude Code CLI provider on a Claude subscription, no API key (CLAUDE_CODE_CLIENT)
  • Claude Code CLI sandbox flags: tools off, settings sources pinned, strict MCP (set_tools_disabled, set_setting_sources, set_strict_mcp_config, verified by extra_arguments)
  • Claude Code CLI session resume: set_resume_session adds --resume "<uuid>"; only a UUID shape is accepted
  • Vector embedding support
  • Semantic similarity search
  • Environment variable configuration
  • Full Design by Contract support
